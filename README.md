# STLR

**Stateful Task Harness-Driven Local Signal Reconstruction on Rotating Component Surfaces**

STLR combines a Reconstruction Task Harness (RTH) with the motion-prior restoration network RSMDNet-P for task-driven local reconstruction of rotating surfaces.

## Release

Source code and datasets will be made publicly available after formal publication of the paper. Dataset downloads will be provided through Google Drive.

## Datasets

- **Task dialogue dataset:** single and interactive restoration requests, task annotations, history for preference reuse, and end-to-end test tasks.
- **Rotating-surface image dataset:** paired degraded and sharp reference images of shaft surfaces, gear tooth surfaces, and tooth-tip planes, with dataset splits, region annotations, and motion priors.

Download links and citation information will be added at release.
