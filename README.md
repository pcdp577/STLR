# STLR

**Stateful Task Harness-Driven Local Signal Reconstruction on Rotating Component Surfaces**

STLR combines a Reconstruction Task Harness (RTH) with the motion-prior restoration network RSMDNet-P for task-driven local reconstruction of rotating surfaces.

## Release

Source code and datasets will be made publicly available after formal publication of the paper.

## Datasets

- **[Task dialogue dataset](https://drive.google.com/drive/folders/1i4Z-n6QW2wCgUqZ3pBoTIeMEvCctUhJm):** single and interactive restoration requests, task annotations, history for preference reuse, and end-to-end test tasks.
- **[Rotating-surface image dataset](https://drive.google.com/drive/folders/1eC11sYLChAUBRksc_6hxC9_rsLg09Y9h):** paired degraded and sharp reference images of shaft surfaces, gear tooth surfaces, and tooth-tip planes, with dataset splits, region annotations, and motion priors.

The Google Drive folders are currently restricted; dataset downloads are not yet available. Citation information will be added upon publication.
